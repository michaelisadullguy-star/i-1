# Rings (`lib/ring.imo`)

Commutative-ring computations: the rings ℤ/n, principal ideals of ℤ and ℚ[x], quotient rings ℚ[x]/(f), the Chinese remainder theorem
for polynomials, multivariate polynomials and **Gröbner bases**.  Every algorithm is written in spec notation in `lib/ring.imo` and
runs in the language, on base-(i − 1) digit strings; the Python host only parses, checks classes and spells digits.

## Representation

* A residue modulo n is a natural number in [0, n); n ≥ 1.  An ideal of ℤ/n is the sorted list of its elements.
* A principal ideal of ℤ is given by a generator, an ideal of ℚ[x] by its monic generator.  Polynomials in one variable are the
  coefficient lists of `lib/poly.imo` (`Poly`, lowest degree first).
* A **multivariate polynomial** (class `MPoly` = `List(Pair(\Q, List(\NN)))`) is a list of terms `pair(c, e)`: a coefficient c ∈ ℚ[i] and
  the list e of the exponents of the variables x₀, x₁, …  (`3*x^2*y - 1/2` in two variables is `[pair(3, [2, 1]), pair(-1/2, [0, 0])]`).
  The monomial order is the first argument of the functions, a natural number: **0** lexicographic, **1** graded lexicographic,
  **2** graded reverse lexicographic.  The canonical form (`mpoly`) has the terms in decreasing order, like monomials merged, no zero
  coefficient and all exponent lists of one length; every function accepts any list of terms (and polynomials of different arity: the
  exponent lists are padded with zeros) and returns canonical polynomials.  The zero polynomial is `[]`.

## ℤ/n and ideals of ℤ

| name | class | meaning |
|:--|:--|:--|
| `addmod(a, b, n)`, `submod`, `mulmod` | `\ZZ -> \ZZ -> \NN -> \NN` | (a ± b), (a·b) mod n in [0, n), negative arguments allowed |
| `negmod(a, n)` | `\ZZ -> \NN -> \NN` | (−a) mod n |
| `zunits(n)` | `\NN -> List(\NN)` | the units of ℤ/n: a with gcd(a, n) = 1 (ℤ/1 is the zero ring; its unit is 0) |
| `zzerodivisors(n)` | `\NN -> List(\NN)` | the zero divisors: a in [1, n) with gcd(a, n) > 1 |
| `znilpotents(n)` | `\NN -> List(\NN)` | the nilpotent elements: the multiples of rad(n) |
| `zidempotents(n)` | `\NN -> List(\NN)` | a with a² ≡ a (2ᵏ of them for k distinct primes) |
| `zideal(n, gens)` | `\NN -> List(\ZZ) -> List(\NN)` | the ideal of ℤ/n generated by integers: the multiples of gcd(n, gens) |
| `zideals(n)` | `\NN -> List(List(\NN))` | all ideals of ℤ/n, one per divisor d of n, by increasing d |
| `zmaxideals(n)`, `zprimeideals(n)` | `\NN -> List(List(\NN))` | the maximal (= prime, ℤ/n being finite) ideals (p), p a prime divisor of n |
| `idealsum(a, b)`, `idealintersect`, `idealproduct` | `\ZZ -> \ZZ -> \NN` | (a) + (b) = (gcd), (a) ∩ (b) = (lcm), (a)(b) = (\|ab\|) |
| `idealcontains(a, b)` | `\ZZ -> \ZZ -> Bool` | (a) ⊇ (b), i.e. a divides b |
| `idealradical(n)` | `\ZZ -> \NN` | the radical of (n): rad(n) |

Related functions of `lib/numtheory.imo` for rings of residues: `modinv`, `powmod`, `ordmod`, `crt`, `totient`, `primroot`, `quadresidues`,
`sqrtmod`, `jacobi`.  The unit group (ℤ/n)× as a permutation group is `unitgroup(n)` in `lib/galois.imo` (it needs `lib/group.imo`).

## Ideals of ℚ[x] and the quotient ring ℚ[x]/(f)

| name | class | meaning |
|:--|:--|:--|
| `polyidealsum(f, g)`, `polyidealintersect`, `polyidealproduct` | `Poly -> Poly -> Poly` | (f) + (g) = (gcd), (f) ∩ (g) = (lcm), (f)(g) = (fg): the monic generator |
| `polyidealcontains(f, g)` | `Poly -> Poly -> Bool` | (f) ⊇ (g): f divides g (the zero polynomial divides only itself) |
| `polyidealradical(f)` | `Poly -> Poly` | the square-free part of f, monic |
| `polyidealgen(fs)` | `List(Poly) -> Poly` | the monic generator of the ideal generated by a list of polynomials (`[]` for the zero ideal) |
| `polyidealmember(p, fs)` | `Poly -> List(Poly) -> Bool` | does p lie in the ideal generated by the list? |
| `qrreduce(f, a)` | | a mod f: the representative of a in ℚ[x]/(f) |
| `qradd(f, a, b)`, `qrsub`, `qrmul` | | a + b, a − b, a·b in ℚ[x]/(f) |
| `qrneg(f, a)` | | −a |
| `qrinv(f, a)` | | the inverse of a (extended Euclid: s·a + t·f = 1), `[]` when a is not a unit |
| `qrisunit(f, a)` | `... -> Bool` | gcd(a, f) = 1 |
| `qrpow(f, a, n)` | `... -> \ZZ -> Poly` | aⁿ by squaring; n < 0 uses the inverse (`[]` when a is not a unit) |
| `qrdimension(f)` | `Poly -> \NN` | dim ℚ[x]/(f) = deg f |
| `qrisfield(f)` | `List(\QQ) -> Bool` | ℚ[x]/(f) is a field ⇔ f is irreducible over ℚ |
| `polycrt(rs, ms)` | `List(Poly) -> List(Poly) -> Poly` | the Chinese remainder theorem: the polynomial p of degree < Σ deg mₖ with p ≡ rₖ (mod mₖ); `[]` when the moduli are not pairwise coprime |

Number fields ℚ(α) = ℚ[x]/(f) (f irreducible) with norms, traces and minimal polynomials are in `lib/field.imo`.

## Multivariate polynomials

`o` is the monomial order (0, 1 or 2), `p`, `q` polynomials, `F` a list of polynomials.

| name | meaning |
|:--|:--|
| `mpoly(o, p)` | the canonical form (sorted, like terms merged, zeros dropped, arity padded) |
| `mpadd(o, p, q)`, `mpsub`, `mpmul` | p + q, p − q, p·q |
| `mpneg(o, p)`, `mpscale(o, c, p)`, `mppow(o, p, n)` | −p, c·p, pⁿ (p⁰ = 1) |
| `mpeval(p, point)` | the value at a point (a list of values for the variables) |
| `mpdegree(p)` | the total degree (−1 for the zero polynomial) |
| `mplc(o, p)`, `mplm(o, p)` | the leading coefficient (0 for the zero polynomial) and the exponent list of the leading monomial |
| `mpderiv(o, p, j)` | the partial derivative with respect to variable j (0-based) |
| `mpsubst(o, p, j, q)` | p with the variable j replaced by the polynomial q |
| `mpstr(o, p)` | text: `"3*x^2*y - z + 1/2"` (variables x, y, z, w, u, v, then x6, x7, …; a non-real coefficient in parentheses) |
| `mpdivide(o, p, F)` | the multivariate division algorithm: (quotients q₁ … qₖ, remainder r) with p = Σ qₖfₖ + r, no term of r divisible by a leading monomial of F, lm(qₖfₖ) ≤ lm(p); the divisors are tried in the order given, a zero divisor never divides |
| `mpreduce(o, p, F)` | the remainder only |
| `spoly(o, f, g)` | the S-polynomial (m/lt f)·f − (m/lt g)·g, m the lcm of the leading monomials |
| `groebner(o, F)` | a Gröbner basis of the ideal ⟨F⟩ by Buchberger's algorithm (with the product criterion; monic elements in the order found; not minimal in general) |
| `reducedgroebner(o, F)` | the **reduced** Gröbner basis: monic, minimal, each element reduced by the others, sorted by increasing leading monomial — unique for the ideal and the order (`[]` for the zero ideal, `[1]` for the unit ideal) |
| `isgroebner(o, G)` | is G a Gröbner basis of the ideal it generates? (every S-polynomial reduces to 0) |
| `idealmember(o, p, F)` | p ∈ ⟨F⟩ ? (the remainder on a Gröbner basis is 0) |
| `idealequal(o, F, G)` | ⟨F⟩ = ⟨G⟩ ? (equal reduced bases) |
| `eliminate(k, F)` | the elimination ideal: a basis (from the reduced lexicographic basis) of the polynomials of ⟨F⟩ that do not involve x₀ … xₖ₋₁ |

Examples (verified by the tests): the reduced lexicographic basis of ⟨x² + y² − 1, x − y⟩ is `{y² − 1/2, x − y}`; of
⟨x² + y + z − 1, x + y² + z − 1, x + y + z² − 1⟩ it is `{z⁶ − 4z⁴ + 4z³ − z², yz² + ½z⁴ − ½z², y² − y − z² + z, x + y + z² − 1}`
(Cox–Little–O'Shea); eliminating x from ⟨x − y², y − y² + 1⟩ leaves `y² − y − 1`.

## Performance

Gröbner bases are doubly exponential in the worst case; the implementation is the textbook algorithm in a language that spends about
10 µs per digit step.  Ideals in 2–3 variables with a few generators of degree ≤ 3 take well under a second to ten seconds (the
Cox–Little–O'Shea example above: 8 s in lex order, 0.2 s in grevlex — choose a degree order when you do not need elimination).

## Tests

`tests/test_ring.py` (21 checks, about 70 s): brute force over ℤ/n for eight values of n; exact polynomial arithmetic in Python for the
ideals, quotient rings and the Chinese remainder theorem; a dictionary-based multivariate arithmetic, division algorithm and Buchberger
algorithm written independently in the test for random polynomials in 2–3 variables and all three monomial orders (including the
division identity and the remainder condition), and the textbook examples above.
